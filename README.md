# Crowd Battle

Unity Version: Unity 6.3 LTS (6000.3.19f1)

Description: Clone Ninja Prototype is a 3D action-platformer prototype built in Unity that centers around a unique clone-summoning combat mechanic. Players can engage in fast-paced melee combat while spawning clone ninjas to attack, distract, and overwhelm enemy AI. The prototype features a complete gameplay loop, including health systems, dynamic Enemy AI (featuring a Boss variant), scene management and Main Menu interface.
